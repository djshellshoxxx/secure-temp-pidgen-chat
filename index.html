How to pick a safe server
  1. Insist on TLS. Use wss:// (WebSocket over TLS) addresses, or TLS ports (IRC 6697) through the bridge. Never plain ws://, port 6667, or XMPP without TLS. Browsers refuse ws:// from this https page anyway.
  2. Check the certificate is valid (padlock). XMPP admins can test servers at compliance.conversations.im.
  3. The server can still see who talks to whom. TLS only protects the road to the server. Only end-to-end encryption (step 2) hides message text from the server's operator - so always turn it on.
  4. Prefer servers with a clear no-logging policy, host/IP cloaking (IRC) and SASL accounts.
  5. Want to hide your IP? Use the bridge with Tor or I2P (step 3).

Install & start the bridge (one paste)
  1. You need Node.js 18+ and, for anonymity, Tor (SOCKS 127.0.0.1:9050) or I2P (SOCKS 127.0.0.1:4447) running.
  2. Press Build the command, then Copy.
  3. Right-click in your terminal (PuTTY: right-click pastes) and press Enter. It writes the file, then starts the bridge. Leave it running.
