# Secure Temp Chat Wiki

A static web app for short-lived, end-to-end encrypted chats over IRC and XMPP, with SILC and GroupWise reachable only
through a gateway you run. The page reports each encryption layer in use, an encryption score and a privacy score. Nothing is
stored: keys, pads, passwords and messages live in the tab's memory.
